# Opportunities

## Steps

1. Search for today's unusual-volume movers, insider transaction filings
   (e.g. Form 4 aggregators), analyst upgrade/initiation reports, and
   52-week high/low breakouts.
2. Filter noise; prioritize signals that have a plausible catalyst
   attached over raw screener hits.
3. Present as a categorized list — Unusual Volume / Insider Buying /
   Analyst Upgrades / Other Notable Signals — each with ticker, the
   signal, and source.

## Notes

- These are observed signals for research/screening purposes, not
  buy/sell recommendations. Unusual activity is not inherently
  predictive, and this should be stated if the user seems to be reading
  it that way.
