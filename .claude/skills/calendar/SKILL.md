# Calendar

## Steps

1. Search the upcoming economic calendar (Fed meetings/speeches, CPI,
   PCE, jobs report, GDP) for the next 1-2 weeks.
2. Search upcoming earnings dates for major names, or specifically for
   any assets the user has been discussing in this conversation.
3. Check for upcoming IPOs or major corporate events (splits, spinoffs,
   index rebalances) in the same window.
4. Present chronologically: Date | Event | Why it matters.
