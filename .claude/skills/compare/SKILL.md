# Compare

## Steps

1. Pull comparable data for both assets: valuation, growth,
   margins/fundamentals (or tokenomics for crypto), recent performance,
   and risk factors.
2. Present the comparison as a side-by-side table across shared
   dimensions.
3. Call out where the comparison is apples-to-oranges (different
   sectors, stage, risk profile) rather than forcing a false
   equivalence.
4. Summarize relative strengths/weaknesses of each without declaring a
   "winner" — the goal is comparison, not a recommendation.

## Output

- Side-by-side table
- Where the comparison breaks down / isn't quite fair
- Relative strengths and weaknesses of each
- One-line disclaimer: informational comparison, not a recommendation.
