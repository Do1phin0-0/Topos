# Coin

## Steps

1. Resolve the symbol to the specific token/network (watch for
   collisions — multiple tokens can share a ticker).
2. Pull current price, recent performance, market cap, and circulating
   vs. total/max supply via web search.
3. Research tokenomics (emission schedule, unlocks, staking/burn
   mechanics), on-chain activity (active addresses, TVL, transaction
   volume), and exchange listings.
4. Build the **bull case** (adoption, network activity, narrative,
   upcoming catalysts) and the **bear case** (unlock schedules, competing
   chains/protocols, regulatory overhang) — present both fairly.
5. List concrete near-term catalysts (protocol upgrades, token unlocks,
   listing/delisting news, regulatory decisions).

## Output

- Snapshot: price, market cap, supply, recent performance
- Bull case
- Bear case
- Near-term catalysts
- One-line disclaimer: this is analysis, not a recommendation to buy,
  sell, or hold.
