# Stock

## Steps

1. Resolve the ticker to a company; confirm exchange/listing if ambiguous.
2. Pull current price, recent performance, and a valuation snapshot
   (market cap, P/E or relevant multiple) via web search.
3. Research recent earnings/guidance, analyst commentary, and major news
   from the last 30-90 days.
4. Build the **bull case** (growth drivers, competitive position,
   catalysts) and the **bear case** (risks, headwinds, valuation
   concerns) — present both fairly; don't let one dominate.
5. List concrete near-term catalysts (next earnings date, product
   launches, regulatory decisions, macro sensitivity).

## Output

- Snapshot: price, market cap, recent performance
- Bull case
- Bear case
- Near-term catalysts
- One-line disclaimer: this is analysis, not a recommendation to buy,
  sell, or hold.
