# Skills

## Steps

1. List every skill currently available to this agent, one line each,
   in the form `/name ARGS — one-line description` (omit ARGS for
   skills that take none).
2. Keep each description to one line; point the user at running the
   skill itself for more depth rather than expanding here.
3. If the user asks about one specific skill afterward, give more
   detail on just that one.
