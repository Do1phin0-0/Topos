# Analyze

The deepest single-asset skill: combine fundamentals, technicals,
sentiment, and macro backdrop into an explicit, falsifiable thesis with a
transparent conviction score.

## Steps

1. Gather fundamentals (financials, growth, moat, or tokenomics for
   crypto), technicals (trend, momentum), sentiment (news/social), and
   macro/sector backdrop.
2. Build an explicit thesis: what has to be true for this to work, and
   what would invalidate it.
3. Weigh the evidence for and against, then assign a conviction score
   (e.g. 1-10 or Low/Medium/High) with the reasoning shown — never a bare
   number.
4. Note the time horizon the thesis assumes (the same evidence can argue
   differently for a trade vs. a multi-year hold).

## Output

- Thesis (what has to be true)
- Supporting evidence
- Key risks / what invalidates the thesis
- Conviction score + rationale
- Time horizon considerations
- Strong disclaimer: this is a structured opinion for research purposes.
  Consistent with this agent's core objective, it is not a recommendation
  to buy, sell, or hold.
